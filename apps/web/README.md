# TiiA Live web app

Next.js App Router site for the DanteFDD event. The main player is Twitch; the selectable MediaMTX/HLS feeds are secondary. Event state and revocable admin sessions use Supabase REST from server-side routes.

Run `npm run dev` for local development. See the repository root `README.md` and `docs/deployment.md` for environment and hosting guidance.

Available checks: `npm test -- --run`, `npm run lint`, `npm run typecheck`, and `npm run build`.
